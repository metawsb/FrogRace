Provably Fair

Before you bet, we commit to a secret Server Seed by publishing only its SHA-256 hash. Every frog stat and jump roll for this race is deterministically derived from Server Seed + Client Seed + Nonce. After the race we reveal the raw server seed so you can re-hash it yourself and confirm it matches the commitment made beforehand — proof the result wasn't changed after you bet.
